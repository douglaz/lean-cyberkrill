`primary.json` contains exactly three captures: the published full string at
line 659, the two-guardian struct at lines 710-737 (`input-2.json`), and the
three-guardian struct at lines 741-776 (`input-3.json`). The example API secret
is the upstream literal `super_secret_api_key`. The published endpoint is
public test input; the other endpoints use example.com.

`capture-fixtures.py` resolves the executable using exactly:

```bash
nix build --no-link --print-out-paths --max-jobs 2 --cores 4 github:douglaz/cyberkrill/27cad1faba86260b06665a89f0af5134d23525c2
```

It runs `fm-encode-invite "$INPUT_JSON"` and `fm-decode-invite "$INVITE"`
inside `unshare -rn`, brings only loopback up, and uses an isolated temporary
HOME. `capture-record.json` records each real command's exit, separated streams
and wall seconds. The three decoded JSON values and exact re-encoded strings
must match. Capture failure stops execution; there is no alternate executable.

`synthetic.json` is generated by `generate-fixtures.py`, without reference CLI
execution. All its expectations are **hand-derived**, traced to the pinned
parser at `lib.rs:99-213`, BigSize at `216-284`, and encoder at `286-380`.
The script is the committed construction. Its independent bech32m checksum
and bit regrouping construct both padding cases and the correctly checksummed
1024-character string over the same 633 bytes used by the encoder test.
These are synthetic bytes and opaque strings, including Unicode and invalid
UTF-8; no wallet, node, credential or device input is used.

The pinned synthetic count is 80: BigSize 12, tagged truncations 14, wider
BigSize 3, four mandatory lax cases 4, part semantics 6, parser errors 13,
encoding 13, normalization 2, wrappers 9, padding 2, boundaries 2. Both Python
and the executable test driver independently pin every collection's count.

`mutations.json` records 31 independent production edits, successful runtime
builds, real failing test exits, their exact detecting assertions and separate
stdout/stderr lines. The checker restores exact original source bytes after
each edit and on managed termination or errors. Its final build and full test
run must pass before it writes the success record. No expectation is mutated.

From this package, with a fresh owned temporary directory in `TMPDIR`:

```bash
python3 capture-fixtures.py --capture
python3 capture-fixtures.py
python3 generate-fixtures.py --write
python3 generate-fixtures.py
nix develop -c lake build
nix develop -c lake test
nix develop -c python3 -I check-mutations.py
```

Use the repository's foreground gate supervision for build/test commands.
The capture script's only network-capable step is the pinned Nix build.
No optional pure Rust probe was used; synthetic cases are not Rust captures.
